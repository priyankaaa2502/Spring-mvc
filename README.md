# Spring MVC Project

This project is a basic implementation of the Spring MVC architecture using Java. It demonstrates how to build a web application using the Model View Controller design pattern with the Spring Framework.

Project Overview

The application is structured to handle client requests using a central controller and route them to appropriate views. It shows how Spring manages request handling, dependency injection, and view resolution.

Features

Handles HTTP requests using DispatcherServlet
Implements MVC architecture
Uses annotation based configuration
Simple controller and view integration
Clean project structure for learning purposes

Technologies Used

Java
Spring Framework (Spring MVC)
Maven
Apache Tomcat
Eclipse or Spring Tool Suite

Project Structure

src/main/java
Contains controller classes and application configuration

src/main/resources
Contains configuration files such as application.properties

src/main/webapp
Contains JSP files and web resources

pom.xml
Manages project dependencies using Maven

How to Run

1. Clone the repository
   git clone https://github.com/priyankaaa2502/Springcore.git

2. Import the project into Eclipse or Spring Tool Suite as a Maven project

3. Configure Apache Tomcat server

4. Run the project on the server

5. Open browser and access the application using the configured URL

Key Concepts Covered

Model View Controller architecture
DispatcherServlet role in request handling
Handler mapping and view resolution
Dependency injection in Spring
Annotation based configuration

Purpose

The purpose of this project is to understand the basics of Spring MVC and build a foundation for developing enterprise web applications.
